# الاختبار

لم تُشغّل هذه الأوامر تلقائيًا. نفذها من جذر المشروع بعد تثبيت الاعتماديات في بيئة معزولة.

## فحوص خفيفة

```powershell
python -m compileall -q app alembic tests
python -m pytest tests/test_security.py tests/test_steam_parser.py
```

## اختبار PostgreSQL والتزامن

أنشئ قاعدة PostgreSQL قابلة للحذف فقط واسمها يحتوي `_test`، ثم:

```powershell
$env:TEST_DATABASE_URL='postgresql+asyncpg://user:password@localhost:5432/steam_codes_test'
python -m pytest tests/test_postgres_concurrency.py
```

الاختبار يرفض العمل إذا لم يكن الاسم يحتوي `_test`. لا تستخدم قاعدة إنتاج مطلقًا.

## الوصول المحلي وتكامل Salla

تشمل `tests/test_salla_integration.py` توقيع webhook وتكامل Demo Store القديم، و`tests/test_salla_notification_parser.py` محلل الإشعارات الإداري المنفصل. مسار `/salla` الجديد لا يستدعي Salla API ولا يقرأ البريد: يطبع/يقبل رقم الطلب كمرجع خارجي غير مُتحقق وينشئ هوية استخدام محلية مع alias غير حساس.

اختبارات PostgreSQL المعزولة لعدادات الاستخدام موجودة في `tests/test_local_access_postgres.py` وتشمل أول مرجع، تكرار المرجع، مرجعًا مختلفًا، خمسة استخدامات، الرفض السادس، النافذة المتحركة، مهلة 30 ثانية، idempotency والتزامن. يجب تشغيلها مع `TEST_DATABASE_URL` يشير إلى قاعدة منفصلة اسمها يتضمن `_test`؛ لا تستخدم قاعدة الإنتاج ولا تُدخل طلبات Salla اصطناعية فيها.

تبقى اختبارات Salla والبريد الإداري منفصلة عن قرار فتح الجلسة المحلية. لا تضع رسالة حقيقية أو بيانات بطاقات أو توكنات في المستودع أو مخرجات الاختبار.

## Smoke Test خارجي

استخدم حساب Telegram وصندوق بريد وعينة Steam مخصصة للاختبار. تحقق من التفعيل، عزل عميل ثانٍ، رسالة قديمة، رسالة غامضة، timeout للبريد، وفشل Telegram. لا تستخدم عميلًا أو حسابًا حقيقيًا في الاختبار.

## فحص بصري

بعد أن يبدأ المستخدم المكدس محليًا، افتح لوحة الإدارة وافحص تسجيل الدخول والخروج وRTL على الهاتف وسطح المكتب والإضافة والتعديل والاستيراد والتخصيص والفلاتر وحالات الفراغ والخطأ، ثم راجع Console وNetwork. لا يعد ذلك مكتملًا بمجرد HTTP 200.
