# تسليم المشروع

- الجذر: هذا المجلد فقط. لا يعتمد على ملفات من مشاريع أخرى.
- الخدمات: `web` و`worker` و`postgres` و`caddy` في `compose.yaml`.
- أسرار مطلوبة: مفتاح التطبيق، مفتاح Fernet للبريد، PostgreSQL، Bot Token، Webhook secret والدومين. لا تحفظها في Git أو وثائق التسليم.
- الحالة الحالية: المدير وصندوق البريد ونسخة السيرفر والنطاق جاهزة. بوابة `/salla` المحلية تقبل رقمًا مرجعيًا غير متحقق ومعرّفًا عاديًا وتطبق عدادات الاستخدام العامة، مع عرض عربي افتراضي ومعاينة إنجليزية اختيارية. Outlook OAuth وصناديق البريد المتصلة تحفظ Refresh Token مشفرًا، وتكامل Salla Demo محفوظ ومصرح إداريًا.
- المنصات: Steam هي المنصة القديمة المفعلة، بينما Ubisoft وRockstar Games مدعومتان لإدارة المخزون والتخصيص الآمن فقط؛ لا يوجد لهما محلل بريد أو تسليم رموز.
- الحدود الحالية: لا توجد خدمة عامة غير حساسة مهيأة تلقائيًا، ورقم `/salla` ليس إثبات ملكية Salla. الصينية والأوكرانية تنتظران عينة `.eml` مستقلة عند الحاجة، والنسخ الاحتياطي يحتاج تجربة استعادة دورية.
- الخطوة التالية: أضف مخزونًا آمنًا من لوحة الإدارة، استخدم صفحة `/salla` بمرجع محلي، وراقب health endpoints قبل أي نشر.
